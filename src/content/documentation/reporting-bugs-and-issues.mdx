We welcome bug reports and issue tickets from everyone.

## Public issues (default)

If your report is not sensitive, please open an issue in our open-source repository:

- [little-world-core on GitHub](https://github.com/a-little-world/little-world-core) [`https://github.com/a-little-world/little-world-core`](https://github.com/a-little-world/little-world-core)

## Sensitive issues (internal)

If the issue contains sensitive details, please report it in our internal development repository instead:

- [little-world-backend on GitHub](https://github.com/a-little-world/little-world-backend) [`https://github.com/a-little-world/little-world-backend`](https://github.com/a-little-world/little-world-backend)

If you need access to create an internal issue, please contact @tim@little-world.com.
