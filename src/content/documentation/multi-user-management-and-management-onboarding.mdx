## Multi User Management and Management Onboarding

Use this process whenever a new team member needs access to the management panel.

### Onboarding steps

1. **Create the management email account**
   - Ask an admin to create a company email address in the `@little-world.com` domain.
   - Example format: `first.last@little-world.com`.

2. **Set the initial password flow**
   - Let the new user set their own secure password for the mailbox/account.
   - Do not share temporary passwords in plain chat when it can be avoided.

3. **Create the Little World user account**
   - The user signs up for a regular Little World account using the same company email.
   - Link: [`https://little-world.com/`](https://little-world.com/)

4. **Grant management permission**
   - Ask a developer or admin to grant base management access after account creation.
   - Without this, the account can sign in but cannot use management functions.

5. **Assign additional permissions in Matching Users**
   - Open: [`https://little-world.com/matching/matching-users/`](https://little-world.com/matching/matching-users/)
   - Select the user and apply the required permissions for their role.

```text
Primary management links
- https://little-world.com/
- https://little-world.com/matching/
- https://little-world.com/matching/matching-users/
```

### Permission points from the labeled image

1. **Can perform matching operations**
   - This is usually required for almost all practical actions in the management panel.

2. **Open-chat permission**
   - This enables access to open-chat tooling and related workflows.

3. **Can send support message replies**
   - This allows replying to user messages through the shared main support account.

4. **Receives Full user access to newly created user**
   - This is required so a management user can actually view user profiles.
   - It also allows scoping access to specific user groups when needed.
